CONTACT IMMINENT v0.4.6.0 — CLEAN KESTREL BASEMAP + GEOMETRIC GRID
Parent gameplay/balance baseline: v0.4.5.5 CONTESTED Pressure Balance.

Visual architecture change:
- Replaced the previous KESTREL raster with the supplied clean AO KESTREL image.
- The raster is now strictly the lowest map layer.
- Added a separate SVG geometric grid layer above the raster and below all tactical content.
- Grid is generated mathematically at runtime from exact regular flat-top hexagons:
    radius = 52 SVG units
    horizontal center spacing = 1.5 * radius
    vertical center spacing = sqrt(3) * radius
    alternating columns offset by half the vertical spacing
- Hexes use identical geometry throughout the AO; no hand-drawn/baked line distortion.
- Grid is pointer-events:none and cannot interfere with map/track/ISR interaction.
- Grid uses vector-effect:non-scaling-stroke and geometricPrecision for consistent line weight.

Layer order:
1. Clean KESTREL raster basemap
2. Geometric SVG hex grid
3. Terrain/tactical features
4. BLUFOR sites
5. threat/sensor overlays
6. tracks + ISR
7. warnings/HUD/UI
